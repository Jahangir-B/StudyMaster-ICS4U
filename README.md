# StudyMaster – Flashcard & Quiz Tracker

## ICS4U Final Project

StudyMaster is a Python application designed to help students create flashcard decks, take quizzes, and track learning progress.

## Features

- Create and manage flashcard decks
- Add, edit, and delete flashcards
- Quiz mode with score tracking
- Statistics dashboard
- File saving and loading using JSON
- Graphical User Interface (Tkinter)
- Object-Oriented Programming design

## Technologies Used

- Python 3
- Tkinter
- JSON
